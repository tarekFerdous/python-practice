# Mission: Python for an AI engineering coding test

## Why
Tarek may be called for a Python coding test for an Applied AI Engineer role (remote Canada), possibly within a week. Passing it is the gate to the offer. He has built real Python projects (Interview Evaluator, Rhubarb) with AI help, but writing Python from a blank file without autocomplete is slow.

## Success looks like
- Solves LeetCode-easy and common medium problems in Python in ~20 minutes, without AI autocomplete, while talking through the approach
- Picks the right data structure (dict, set, list, deque, heap) and states the Big-O unprompted
- Writes practical "real job" Python fast: parse/aggregate data, a small class (LRU cache, rate limiter, retry), and AI-flavoured tasks (text chunking, cosine top-k, validating LLM JSON, asyncio concurrency)
- Writes a quick pytest check for his own function

## Constraints
- About one week; format unknown (could be live pair-programming or a timed online test), so prepare for both
- Highest-yield patterns first; lessons short; practice with automatic feedback (pytest)
- Practise with Copilot / AI autocomplete turned off

## Out of scope
- Deep CS theory (proofs, advanced graph algorithms, dynamic programming beyond the classics)
- Frameworks beyond what a test could ask (no Django; FastAPI only if it comes up)
