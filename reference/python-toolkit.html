Hash maps (Lesson 1)

seen = {}                            # "have I seen it?" → O(1)
for i, x in enumerate(nums):         # index + value
    if target - x in seen: ...
    seen[x] = i
d.get(key, default)                  # no KeyError

from collections import Counter, defaultdict
c = Counter(words)                   # counts
c.most_common(k)                     # ties: first-seen order, NOT alphabetical
g = defaultdict(list); g[k].append(v) # grouping; .get() won't create the default

sorted(xs, key=lambda w: (-c[w], w)) # tuple key: count desc, then A→Z
"".join(sorted(word))                # anagram signature: "tea" → "aet"

Spot it: a nested loop whose inner loop searches for something → store what you've seen in a dict or set.

Two pointers and sliding window (Lesson 2)

left, right = 0, len(s) - 1          # both ends → meet in the middle
while left < right: ...              # palindrome, pair sum in a SORTED list
ch.isalnum(), ch.lower()             # skip non letters/digits; ignore case

window = sum(nums[:k])               # fixed window: in one, out one
window += nums[r] - nums[r - k]

left = 0                             # variable window
for right, ch in enumerate(s):
    # add ch; while invalid: drop s[left], left += 1
    best = max(best, right - left + 1)   # +1: both ends inclusive

Spot it: "consecutive", "subarray", "substring" → sliding window. "Sorted" + a pair/triple → pointers from both ends (O(1) space vs the dict's O(n)).

Stacks, deque and heapq (Lesson 3)

stack = []; stack.append(x); stack.pop(); stack[-1]   # LIFO, O(1); check `if not stack` first

from collections import deque
q = deque(); q.append(x); q.popleft(); q[0]          # FIFO, O(1) both ends (list.pop(0) is O(n))

import heapq                                         # MIN-heap on a plain list
heapq.heappush(h, x); heapq.heappop(h); h[0]         # O(log n), O(log n), O(1)
heapq.heapify(nums)                                  # O(n), in place
heapq.heappush(h, -x)                                # max-heap: negate
heapq.heappush(h, (priority, i, item))               # tuples compare left to right
heapq.nlargest(k, nums)                              # O(n log k)

Spot it: matching / nesting / "most recent first" → stack. "Oldest first", events in the last N seconds, BFS → deque. "Top k", "k-th largest", "merge sorted" → heap.

How to talk in a live test

  1. Restate the problem; ask about edge cases (empty, duplicates, negatives, size of n).
  2. Say the brute force and its Big-O.
  3. Say the better idea ("a dict of value → index lets me…"), then code it.
  4. Trace one example by hand; state the final time and space complexity.
