1. Two pointers from both ends

Put one index at the start and one at the end, and move them toward each other. The Handbook's tip for strings: "Have two pointers at the start and end of the string."1 Each step moves one pointer inward, so the loop runs at most n times: O(n) time, O(1) space.

left, right = 0, len(s) - 1
while left < right:                # stop when they meet
    if s[left] != s[right]:
        return False
    left += 1
    right -= 1
return True

For your exercise, also skip anything that isn't a letter or digit. ch.isalnum() tells you2 and ch.lower() ignores case. Skip by moving one pointer and checking again; don't build a cleaned copy (that costs O(n) space).

When the list is sorted, pointers replace the dict

Pair sum on a sorted list: add the two ends. Too small? Only moving left right can make it bigger. Too big? Move right left. Each step throws away one number for good.

total = nums[left] + nums[right]
if total == target: return (left, right)
elif total < target: left += 1      # need bigger
else: right -= 1                   # need smaller

Interview line: "Since it's sorted, I can use two pointers for O(1) space instead of the O(n) dict from Two Sum." Naming that trade-off is points.

2. The sliding window

Both pointers move the same direction and never pass each other, so each element enters and leaves the window at most once: O(n).3 Use it whenever a question says consecutive, subarray or substring.

Fixed size k: slide, don't re-add

Re-summing every window of k is O(n·k). Instead, add the number entering on the right and subtract the one leaving on the left:

window = sum(nums[:k])             # first window
best = window
for right in range(k, len(nums)):
    window += nums[right] - nums[right - k]   # in one, out one
    best = max(best, window)

Variable size: grow right, shrink left

The template for "longest substring such that…": extend right every step; while the window breaks the rule, move left forward. Record the best length while the window is valid.

left = 0
for right, ch in enumerate(s):
    # 1. add ch to the window
    # 2. while the window is invalid: remove s[left], left += 1

For "no repeated characters", a set of what's in the window (Lesson 1's O(1) lookup) tells you when it's invalid. Window length is right - left + 1, the classic off-by-one spot.
